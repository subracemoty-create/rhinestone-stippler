# Rhinestone Stippler

Portrait → stippled rhinestone template (weighted Voronoi stippling).
PNG (with DPI, transparent) and SVG cut file in real millimetres.

**Live app:** https://subracemoty-create.github.io/rhinestone-stippler/

Open it on the phone in Chrome → **Install app** for a home-screen icon.
Works offline after the first visit. `index.html` also runs on its own by double-click.
